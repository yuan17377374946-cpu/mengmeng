# 小数除法全章学习与闯关

依据：用户提供的五年级数学课本第24–38页，共15页。网络来源见网页“资料依据”。

## 内容覆盖

| 分类 | 关卡 | 重点 |
| --- | --- | --- |
| 计算 | 1–5 | 小数点、商0、添0、商不变、除数整数化、验算纠错 |
| 概念 | 6–10 | 有限和无限小数、循环节和简写、比较、近似数、商大小 |
| 取值 | 11 | 四舍五入、去尾、进一；整除不加1 |
| 应用 | 12–22 | 单价、包含分、倍数与单位、面积反求、速度、相向、购物、预算不变、单位量、分段收费、两种取值数量链 |
| 可选提升 | 23–24 | 等式和数列、小数点倒推、限定两位小数的舍入范围 |
| 网络查漏 | 25–27 | 余数原单位、除和除以、混合运算、舍入边界和末尾0 |
| 可选提升 | 28 | 非纯循环小数的循环节和指定数位 |

共28关，每关6题，168题。150题核心／查漏，18题可选拓展。网络补充为自行编写的配套题，不是直接复制网络试卷。

## 使用建议

先做3道计算诊断，再按表现选择关卡，不安排一次刷完。每题要求读题、解释两个量、列式、说明商的意义，最后检查单位和取值。90分钟详细安排在网页“备课”。

综合测试30题：25个非拓展关卡各1题，再补5道应用题。无倒计时，交卷前不显示解析，不带入之前练习保存的思路。每题1分，只计最终答案，竖式和过程由教师另评。
