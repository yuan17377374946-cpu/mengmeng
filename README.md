# 英语与数学学习网页

这里包含五年级英语第二单元网页，以及两套可以独立使用的小数除法练习网页。

| 网页 | 内容 | 入口 |
| --- | --- | --- |
| 英语第二单元 A Green Life | 20关、160题；19项单词拼写、30题课堂测试、知识清单、错题复练与写作 | [english-unit2/index.html](english-unit2/index.html) |
| 应用题专项 | 10关、50题；先列算式，再填写答案；支持错题重练 | [index.html](index.html) |
| 第三单元全章闯关 | 28关、168题；知识清单、易错查漏、错题复练、30题综合测试、90分钟备课安排 | [unit3/index.html](unit3/index.html) |

## 使用

下载仓库后，用浏览器打开 `english-unit2/index.html` 进入英语闯关。打开根目录 `index.html` 进入数学应用题专项；点击其中的新版入口进入全章学习。也可以直接打开 `unit3/index.html`。

保留完整目录，HTML、JavaScript、CSS需要放在对应位置。无需安装依赖或构建。若仓库已启用GitHub Pages，两套网页使用相同目录结构即可访问。

学习进度保存在当前浏览器。三套网页使用独立的记录键。不同设备、不同浏览器，以及本地文件和在线网页之间不会自动同步进度。

原18关网页备份保留在 `archive/`，不覆盖或删除。

## 英语第二单元

`english-unit2/`包含完整的HTML、JavaScript、CSS与题库。20个关卡全部开放，覆盖单词词组、祈使句、can/should、代词、教材阅读、环保表达和写作。19项教材词汇另有拼写专项。30题课堂测试在交卷后显示解析。

网页内置发音功能使用浏览器提供的语音；设备可用声音可能不同。写作由教师检查，答案计分不替代作文评阅。

## 数学全章内容与备课

全章网页依据课本第24–38页整理，并加入单独标注的网络易错查漏。25个核心／查漏关卡、3个可选拓展关卡；每关6题。综合测试覆盖25个非拓展关卡，再补5道应用题。交卷前不显示答案，不带入练习时保存的思路。

具体覆盖表、课时建议与资料边界见 [备课说明](unit3/teacher-notes.md)。参考来源在全章网页的“资料依据”中。
